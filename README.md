# 📌 DemoApplication.java
스프링 부트 애플리케이션 시작점

---

## 📦 domain/ (JPA 엔티티)
DB 테이블 구조 그대로 매핑

| 클래스               | 설명                                  |
|----------------------|---------------------------------------|
| `User`               | 회원 기본 정보 (닉네임, 이메일, 비밀번호 등) |
| `UserProfile`        | 회원 성향 프로필 (나이, 성격 등)             |
| `UserInterest`       | 자유입력 취미                            |
| `OptionCategory`     | 선택 항목의 카테고리 (ex. 청소, 흡연)         |
| `OptionValue`        | 카테고리에 해당하는 선택 값들                |
| `UserSelectedOption` | 프로필이 선택한 항목 기록                    |

---

## 📨 dto/

| DTO               | 설명                                          |
|--------------------|-----------------------------------------------|
| `AddUserRequest`   | 회원가입 시 클라이언트가 보낸 정보 (닉네임, 이메일, 비밀번호) |
| `LoginRequest`     | 로그인 시 닉네임 + 비밀번호                          |

---

## 🔁 repository/

| 클래스           | 설명                                                 |
|------------------|------------------------------------------------------|
| `UserRepository` | `User` 엔티티용 JPA Repository (아이디/이메일 존재 여부, 로그인 시 조회) |

---

## 🧠 service/

| 클래스         | 설명                                                   |
|----------------|--------------------------------------------------------|
| `UserService`  | 회원가입 및 로그인 로직 처리 (비밀번호 암호화 ❌ 평문 저장/검사) |

---

## 🌐 controller/

| 메서드         | 경로             | 설명             |
|----------------|------------------|------------------|
| `register()`   | POST `/api/user` | 회원가입 API      |
| `login()`      | POST `/api/login`| 로그인 API        |
